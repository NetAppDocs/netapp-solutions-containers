= Learn about VMware vSphere Kubernetes Service with NetApp ONTAP
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
VMware vSphere Kubernetes Service (VKS) is a managed Kubernetes offering from VMware that enables organizations to deploy, manage, and scale containerized applications using Kubernetes. Paired with NetApp ONTAP storage, VKS delivers enterprise-grade persistence, performance, and data management for cloud-native workloads.

VKS is embedded in VMware Cloud Foundation (VCF) and conforms with upstream CNCF Kubernetes, ensuring compatibility with the broader Kubernetes ecosystem and tools.

== Key features of vSphere Kubernetes Service

. *Managed Kubernetes Clusters:* vSphere Kubernetes Service simplifies the deployment and management of Kubernetes clusters. It automates tasks like cluster creation, upgrades, scaling, and monitoring.

. *Integration with VMware Infrastructure:* VKS integrates seamlessly with VMware vSphere, NSX-T, and other VMware solutions, enabling organizations to leverage their existing VMware infrastructure for Kubernetes workloads.

. *Multi-Cloud and Hybrid Cloud Support:* vSphere Kubernetes Service supports deployment on private clouds, public clouds (e.g., AWS, Azure, Google Cloud), and hybrid cloud environments, giving organizations flexibility in managing their applications.

. *Built-in Security:* VKS includes security features such as role-based access control (RBAC), policy enforcement, and integration with VMware NSX for network security.

. *Support for Kubernetes Ecosystem:* VKS supports the full upstream Kubernetes API, ensuring portability across environments and compatibility with the broader Kubernetes ecosystem, including tools like Istio for service mesh, Prometheus for monitoring, and other CNCF-certified tools. Organizations can apply standard Kubernetes skills and integrations directly to VKS clusters.

. *Developer-Friendly Tools:* VKS supports standard Kubernetes developer workflows, including CI/CD pipelines, GitOps practices, and tools like kubectl and Helm, enabling development teams to build and deploy containerized applications without learning proprietary interfaces.

. *Scalability and High Availability:* VKS offers features like auto-scaling and fault tolerance to ensure applications remain highly available and performant.

. *Observability and Monitoring:* VKS integrates with standard Kubernetes-compatible monitoring tools to provide real-time insights into cluster and application performance.

== Use cases for vSphere Kubernetes Service

. *Application Modernization:* Organizations can modernize legacy applications by containerizing them and deploying them on Kubernetes clusters managed by VKS.

. *DevOps Enablement:* VKS supports DevOps workflows by providing automation, CI/CD integration, and developer-friendly tools.

. *Hybrid Cloud Deployments:* Enterprises can use VKS to deploy Kubernetes clusters across on-premises and cloud environments, enabling consistent operations.

. *Microservices Architecture:* VKS supports microservices-based application development, allowing teams to build and scale distributed systems.
